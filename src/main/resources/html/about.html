About EXTRARNAS

EXTRARNAS is a standalone desktop application designed to analyze RNA 3D structures and extract their secondary structures and base-pairing interactions using specialized bioinformatics tools in containerized environments.

It supports the extraction of canonical cis Watson–Crick base pairs (A-U, G-C, and G-U) as well as all Leontis–Westhof base-pair types.

EXTRARNAS leverages Docker to execute tools such as X3DNA-DSSR and others in isolated and reproducible environments.
